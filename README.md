# 🔦 Prakashit Bhavah

**An iconic gesture. A universal Android experience.**

Prakashit Bhavah brings Motorola-inspired double-chop flashlight control to Android smartphones across manufacturers.

Perform two quick chopping movements to instantly toggle your flashlight — without unlocking your device or touching the screen.

### ✨ Features

- **Double-Chop Gesture:** Instantly toggle the flashlight using motion.
- **Universal Android Compatibility:** Designed for Samsung, Xiaomi, Vivo, Motorola, Pixel, OnePlus, and more.
- **Background Monitoring:** Gesture detection through Android foreground services.
- **Smart Pocket Protection:** Uses proximity and ambient light sensors.
- **Haptic Feedback:** Subtle vibration on every flashlight state change.
- **Adaptive Sensor Detection:** Adjusts to available device hardware.
- **Gesture Calibration:** Customize sensitivity for different smartphones.
- **AMOLED Dark Interface:** Minimal, modern design.

### 🛠️ Technology

- Kotlin
- Jetpack Compose
- Android SensorManager
- CameraManager API
- Android Foreground Services

### 🎯 Vision

Make gesture-controlled flashlight functionality accessible to Android users everywhere, regardless of smartphone manufacturer.

**One gesture. One light. Limitless possibilities.**
